# A+ Media Model
A [PHREEQC model](https://www.usgs.gov/software/phreeqc-version-3) (v3) of [A+ media](https://onlinelibrary.wiley.com/doi/abs/10.1111/j.1529-8817.1973.tb04116.x) to predict DIC speciation from headspace pCO2. This contains data to reproduce results from Hurley et al. 2026 (forthcoming).
